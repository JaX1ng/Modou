    克制关系

    拳克腿克重克拳

    • 每一招都有起手和主系：单招两者一样；连招的起手是第一下，主系是最后一下。比如「拳→重」崩拳 = 起手拳、主系重。
    • 两边同时打中，先比主系：克制的一方克，单方面打中 ×1.3。
    • 主系一样再比起手：克制的一方压，两边都打中，被压的吃全额、被打退，压人的只吃三成还能接着打。
    • 主系、起手都一样 = 平（拼招），各掉五成血、互相震退。
    • 拳克腿：起腿时被拳打中会失衡倒地。腿克重：重拳起手被化解。重克拳：重拳前摇霸体硬吃一记短拳。
    • 打击克擒拿，擒拿克格挡；腿克对空，对空（托天掌、冲天炮）克空中招；空中互撞也按起手分压。完整对照看下面「组合克制总表」，每种技术的破法看「破解表」。
    • 空中交手：空中出招被克制它的招打中 = 倒栽葱，摔下来倒地更久；空中的腿撞上地上的腿 = 空中那个翻滚回去，只吃一半伤害、往后翻开一大段。

    攻防规则

    • 格挡：伤害只吃三成；被挡的一方「势破」，下一记短拳前摇 +4 帧。按住格挡再按方向能边挡边走（往后退也一直面朝对手）。
    • 高低：下盘拳、扫堂腿是下段，要蹲着挡；空中招是上段，要站着挡。
    • 连击衰减：同一套里每多挨一下，硬直更短、被推得更远、伤害更低，连四五下就断。
    • 倒地：躺一会儿 → 起身（打不中）→ 起身硬直（站起来那几帧，打得中、动不了）→ 能动。倒了就是起身后被动：对面能压你起身，你能滚身起。
    • 擒拿挡不住，但站着抓不到蹲着的人（要用蹲+拿「抄腿」，抄腿又抓不到站着的）；对方出腿时擒拿 = 接腿摔，跳起来踢的倒地更久。被抓住马上按拿能挣脱。
    • 防守反击：挡住以后打中对方还没收完的那一招 = 挡后反击 ×1.3，那一招是击倒招 ×1.5。重系、腿系的招被挡住收招更慢、也弹不远（击倒招更慢），挡住了上前一步就打得到；短拳被挡住还是推得开。卸力后打中 ×1.35；击倒招打空了被打收招 = 破绽 ×1.25。被打中的硬直也更长，好接连招。
    • 朝向：按着方向不出招就是跑，马上朝那边跑（没有后退，也不会被吸回去）。不按左右（站着、蹲着）、格挡、挡住的硬直里，自动面向对手，对手跳到身后马上转过来。出招时对手在近身范围内一律朝他打（乱按方向也不打空，对手在空中按他快落到哪算），远了才照你按的方向。背对着挨打挡不住。
    • 跑着能从对手身边挤过去，换到另一边。
    • 跳跃：按着方向跳能跳很远，跑起来再跳更远；空中按方向只能小幅调整，松开就慢慢停下。
    • 跳起出招 ×1.35，每跳一招，出手时人往前下方扑，整个跳跃过程都打得到地上的人；落地前来不及出完，就变成落地后马上出。蹲下能躲飞踢。
    • 趁对方前摇打中 = 破招 ×1.2；打在全速跑过来、或冲刺收尾的人身上 = 迎击 ×1.2。
    • 气：挨打、格挡、打中都会涨，挨打涨得最多。

    组合克制总表

    行是你的招，列是对手同时出的招。名字是「起手 + 主系」，例如「拳重」= 拳起手、重收尾（崩拳）。鼠标停在名字上能看到包含哪些招。克单方面打中 压两边都中、你占大便宜 平拼招 被压 被克

    破解表

    每一种招、每一种技术都有破法。训练场的「破招练习」里一条一条都能对着木桩练（木桩照着出那一招，带说明和演示）；也能把木桩设成站挡、蹲挡、乱挡、一直跳，自己对着练。

    帧数表

    招式起手主系段前摇判定后摇伤害射程

    1 帧 = 1/60 秒（1.8.0 整体慢约 7%，1.9.3 出招再慢约 5%；2.0 起手招（中立时出的第一招）前摇、后摇再一起慢一点，看得清对面出什么）。射程是两人中心距（像素，含前冲），空中招式伤害已含 ×1.35。段：中段站蹲都能挡，下段要蹲挡，上段要站挡。血量 500，五局三胜。
