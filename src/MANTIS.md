## 一、一句话：快 · 勾 · 蹦

- **快（全派没有慢招）**：站着出的拳 / 重 / 踢起手前摇 4 / 8 / 8 帧（基准帧数；格斗术 4 / 18 / 19.5，太极 18 起）—— 四派里唯一重、踢也快的。代价是一下轻：崩捶 6、劈掌 11、勾踢 9（格斗术 6 / 16 / 13），要多打一倍的下数才打得掉同样的血；轻拳挡住又不掉血，所以不能光按，要靠勾和上下段开路。
- **连环（螳螂连）**：打中、被挡住随便接（拳重踢拿都接得上），一串最多 8 下。**越连越快**：一串里每多一下，下一招前摇 −`MT_ACC`（1）帧，最少 `MT_S_MIN`（3）帧 —— 第三下起对面反应不过来，只能一直挡。**气短**：第三下起每多连一下，这一招的收招多 `MT_WIND`（2）帧；一串在哪一下停下来，哪一下就喘这么多（八连停在第八下 = 多喘 12 帧）—— 一直按、最后一下被挡住 = 大破绽。要么接着连（他挡着不掉血，你在白喘），要么蹦出去。
- **勾（拿 = 勾搂）**：螳螂手往前一勾（基准前摇 5 帧，实际 6.5；收手 15，实际 20.5）：
  - 他正出手上的招（他那一招打到之前 `MT_HOOK_EARLY`（10）帧以内 / 判定里，拳、掌、肘，不算下段、跳起来的）= **勾住**：他那一招没了，被勾到你面前（拉到 `MT_PULL_GAP`）失衡 `MT_HOOK_STUN`（22）帧，你收手只要 `MT_GOU_R`（6）帧、马上能动，接着打中 ×`MT_HOOK_MUL`（1.3）「勾打」（只加第一下）。这是螳螂拳的卸力：不是挡着等，是看见他出手伸手去勾。勾得住慢招（重拳、腿踢的 18 帧前摇看得见），勾快招（短拳 5.5 帧）得猜：量过，勾手要比他的拳早一帧按才勾得住，同一帧按是挨打。
  - 他正出腿 = **搂腿**：接住腿往下一搂，打倒（接腿摔那一类，`CATCH_DMG`）。蹲 + 拿 = 低搂，搂得住扫堂腿、采得住蹲着的人。
  - 他站着、挡着、收招里 = **采手**：抓住手腕往怀里一带，他硬直 `MT_CAI_STUN`（17）帧、被拉到面前，你先动 —— 不是擒住：没有后续选择、挣不脱、也不疼（`MT_CAI_DMG` 3）。对面老举着手挡，采一下接一记崩捶，一串就开了。**他正硬直着（挨打、挡住的硬直里）采不住 = 采空**（做的时候发现：挡住一下接采手、再崩捶、再采手是个挡不住的循环，所以硬直里的人只能挂手勾、不能采）。
  - 勾空了、勾到蹲着的（站着的勾抓不到蹲着的）、采空 = 大破绽（收手 20 帧）。已经打到你身上、被你挡住的那一下勾不住（不然挡住以后 1 帧的挂手回回勾住他还没收回去的手）。
  - **太极拳正打出来的招身上有掤：勾被掤开**（他劲 +1、那一招照打，你勾空）—— 做的时候满级螳螂打满级太极六成四，太极的招全是慢招、一抬手就被勾；加了拳派钩子 `hookResist`（`TAIJI.md`）以后四成八。蓄着站那儿的太极照旧勾得住（擒拿克蓄），腿照旧搂得住，下段的撩掌化不了。
- **挂手（挡住的硬直里按拿）**：1 帧起手的勾（`mtGuaShou`，判定 4 帧，收手 16 → 实际 19），不管他那一招走到哪（`hookEarly` 99，刚起手第 0 帧也算）都挂得住 —— 挡住他一下，硬直里按拿，他接着打过来的手就被挂住 = 勾住一整套。这是螳螂拳的「接招」（咏春按住挡再按键、太极按后捋、格斗术松开再按挡卸力、螳螂硬直里按拿）。**挂手只勾**：他接着出的是腿、擒拿，或者根本没接着出 = 挂空（一样 19 帧；做的时候挂手对着不接着打的人变成采手 —— 每一记被挡住的短拳都能白罚，比卸力还稳，改了）。
- **蹦（后 = 蹦步退）**：出招打中或者被挡住以后（判定出来了），按住后（离开对手的方向）= 收招直接换成往后一蹦（`MT_HOP` 14 帧、腾空 `MT_HOP_FLY`、退 `MT_HOP_PX` 74 像素），不吃气短，脱出他的射程。**挡住的硬直里按住后也蹦**（从挡住硬直里脱出去）。`MT_HOP_COOL`（36 帧）一次。蹦不无敌、不挡：落地前不能挡、不能出招，被连珠快拳压着的时候蹦到一半被打在空中。打空了不能蹦（打空就是破绽）；勾搂、封手、空中招、出招的时候已经按着后的（撤步崩）不蹦。打中 → 接着连；被挡住 → 蹦出去或者采手开路：螳螂拳的回合就是这么走的。冲刺叫蹦步进（猴步），跑得比别人快一成（`MT_RUN` 1.12）。
- **弱点**（Jack：快，但是有弱点在那里）：
  - **薄挡**：挡住重系、腿系、空中招、对空、大招（轻拳一系、推挡照旧）—— 挡住掉的血在通用的三成（`BLOCK_KEEP`）上再多 `MT_GUARD_CHIP`（一成，一记 16 的重拳别人掉 5、螳螂掉 7），挡住的硬直多 `MT_GUARD_ADD`（4）帧，被推得远 `MT_GUARD_KB`（×1.5）：对面的重拳、腿踢打在螳螂的架子上是赚的，挡着不动会被压死。办法是勾（看见重招伸手勾）、蹦出去、或者先手。
  - **没有卸力**（`parry: false`）：刚按下挡不是卸力，勾才是。
  - **一下轻**：同样的下数打不过人，靠连、靠勾打、靠上下段（劈掌上段、撩掌下段）。
  - **勾空、停手都是破绽**：勾是读他出手，读错了 20 帧收手；一串停在后半段多喘。
  - **采手只是短硬直**：对面蹲着、不出手，勾也抓不到。

## 二、难度和上限（Jack：像王者的妲己 / 露娜，每一派有自己的操作难度和上限）

- **格斗术**：中等，上限在读招破招。
- **咏春拳**：最难（拍子、接招、搭手），上限最高。
- **太极拳**：上手容易，上限中等。
- **螳螂拳：中等偏难（量出来 4.5 星，和咏春的 4 星挨着：下限低），上限中高（满级对三派 50.4%，咏春 54.2、太极 52.5、格斗术 44.6）**。乱按也能打（快、连得上、不用按拍子），但乱按吃亏：轻拳挡住不掉血、停手就喘、挡重招就被压。打得好要会三件事 —— 看见他出手去勾（慢招好勾、快招靠猜）、被挡住的那一下蹦出去（或者采手开路）、劈掌 / 撩掌上下段换着打。打它：站着挡它的轻拳不掉血，等它停手罚它的喘；它要勾就蹲（抓不到蹲着的）或者出腿晚一点（勾只勾手上的招的前摇后段）；它薄挡，重拳、腿踢往它架子上砸；它蹦出去别追空，等它再进来。

## 三、按键（站着）

| 键 | 招 | 说明 |
|---|---|---|
| 拳 | 崩捶 | 前手拳背往前一弹，最快的起手（4 帧） |
| 前 + 拳 / 后 + 拳 / 蹲 + 拳 | 圈捶 / 撤步崩 / 撩掌 | 上步绕一个圈砸进去（射程长、往前冲）/ 一边退一边弹一拳（拉开距离）/ 蹲下往上一撩（下段） |
| 重 | 劈掌 | 掌从头顶劈下来：上段（蹲着挡不住），前摇 8 |
| 前 + 重 | 砸捶 | 上步一拳砸下去（最疼的起手 13） |
| 蹲 + 重 | 挑掌 | 对空：往上一挑，打跳过来的人 |
| 踢 / 前 + 踢 / 蹲 + 踢 | 勾踢 / 蹬扑 / 低勾踢 | 前腿往里一勾（中段）/ 脚底板往前一蹬，把人蹬开 / 贴地一勾，勾倒（下段，打倒） |
| 拿 / 蹲 + 拿 | 勾搂 / 低搂 | 第一节的勾：勾住、搂腿、采手 |
| 挡 | 封手 | 薄挡（第一节）；按着挡走 = 猴步（和别人一样慢）；挡住按拳 = 封手推开（推挡，`sinv` 前 6 帧打不中）；挡住按重 = 挂捶（花气，像截击：挂开他的手顺势一捶，收势） |
| 挡住的硬直里按拿 | 挂手 | 第一节的挂手：1 帧起手的勾 |
| 出招打中 / 被挡住以后按住后；挡住的硬直里按住后 | 蹦步退 | 第一节的蹦 |
| 气满 重 + 踢 | 螳螂扑蝉 | 大招：扑进去双手一勾一劈，打中发人出去 |
| 跳起来 拳 / 重 / 踢 / 蹲 + 踢 | 飞崩 / 腾空劈 / 腾空勾踢 / 坠枝 | 空中招，和别的派一个规矩 |

连环（打中 / 被挡住马上按，一串最多 8 下，越连越快、停下越喘）：

- 拳起手：拳拳 翻车（后手一劈一翻）→ 拳拳拳 圈捶（把人打远一点）；拳重 补捶、拳拳重 双封手（两掌一起封出去，打倒）；拳踢 勾踢；拳拿 勾搂（他挡着就采一下开路）。
- 重起手：重拳 偷手（劈完藏在下面的拳偷偷弹出来，3 帧）；重重 劈砸（一劈一砸，打倒）；重踢 蹬扑。
- 踢起手：踢拳 落步崩；踢重 落步劈；踢踢 鸳鸯腿（两腿连环，第二腿勾倒）。

## 四、引擎里改的（每一派都能用，螳螂先用）

- `combat.js grabIntent`：招身上写 `hook: true` 的拿 —— 和咏春的拉手（`trap`）一样抓得住正出手上的招的人（判为 `trap`），抓得多早看 `hookEarly`（咏春的拉手还是 `WC_TRAP_EARLY`）；拉手接不住腿，勾手接得住（走通用的 `catch`）。
- `combat.js applyHit`：失衡的种类 `reelKind === 'hook'` 打中 ×`MT_HOOK_MUL`（`REEL_LABEL.hook = '勾打'`），和捋的 `lu` 并排。
- `fighter.js runSpeed`：拳派表里写 `runMul` 跑得快慢（螳螂 `MT_RUN`）。
- `fighter.js` 挡住的硬直里也问拳派的 `input(F, 'blockstun', locked)`（返回 true 就接管这一步：螳螂的挂手、从挡住硬直里蹦）；`mtHeld`（被勾住 / 采住、正被拉过去）在挨打结束、倒地时清掉；快照 `record()` 多了 `hop`（在蹦）、`hook`（伸着手勾）、`mtWind`（停手在喘）三个字段给电脑看。
- 钩子：`input`（'attack' 越连越快、气短、蹦步退、取消接招、勾住 / 采手的那几步拉人；'blockstun' 挂手、蹦）、`defend`（薄挡）、`strike`（没有）、`grab`（勾住、采手 / 采空、搂腿）、`target`（待机的呼吸、勾住 / 采手时前手搭在他手腕上）、`drawCue`（勾住的时候手腕上一圈）。
- 蹦步退按的是「按住后」不是「按一下后」：出招开始那一帧记下有没有按着后（`m.mtBack0`），出招中途才按下的才算 —— 以前用边沿检测，打中停顿（freeze）那几帧 `update` 不跑，边沿漏掉；按住也让 2 帧一步的测试台按得出来。挡住硬直里的蹦看的是**挡住之前那一帧**按没按着后（站着、挡着的时候 `input(F, 'neutral')` 每帧记 `mtBackPrev`）：边挡边退的人挨上一下不蹦，挡住的停顿里才按下后的蹦 —— 停顿里这个钩子不跑，不能看「第一次跑到的那一帧」（做的时候电脑在停顿里按下后，第一帧看见已经按着了，当成本来就按着，蹦不出去）。
- 螳螂的字段 `mtHopAt`（上一次蹦）、`mtHeld`、`mtBsSer` / `mtBsBack0` / `mtBackPrev`、`mtHookLimb` 在 `Fighter.reset()` 里清（钟每回合归零，不清 `mtHopAt` 下一回合开头蹦不了）；都是普通值，自动进存档。

## 五、电脑（`KITS.mantis`；两边智能性相等；数都在 `ai.js` 的 `M_AI`）

- 螳螂拳的电脑：看见他出手上的招、来得及就伸手去勾（`mantisReact`，机会 = 读招的本事 × `M_AI.hook` × `M_AI.read[档]`；时机照咏春拉手的 `trapAt` 算；1 帧看穿的 `hellCounter` 里勾 `trap` 是慢招的首选），慢招（前摇 12 帧以上）几乎必勾、快招靠看穿；腿 —— 搂腿或者拳打单脚站着的；他站着挡就采手开路（`M_AI.cai`，满级少采：6.5 帧的手满级看得见）；被挡住的那一下、一串连到后半段被挡住就蹦出去（`M_AI.hop`），打中了、打完了也常蹦（`M_AI.hopHit`：站在他面前等他硬直完就是挨打）；一串打中了接着连到底（连招表 `MPLANS` 多是三到六下，拳重踢换着来；勾住 / 采住以后的一套在 `hookFor` 那一行挑，**看的是真的他在不在硬直里**，不是看见的：满级看见要 7 帧，勾住的硬直早过了一半 —— 做的时候这里错过，崩捶回回打在他硬直刚完、按住挡的那一帧上被卸力）；被压制时缝里的答案（`prPlan`）：挡住硬直里**挂手**（他下一下来之前两三帧按；连珠快拳来得正好在硬直完的时候就硬直最后一帧按，1 帧起手 4 帧判定还挂得住）、缝够就勾 / 崩捶、缝不够蹦（他两下隔 12 帧以上才蹦）、封手推开；对面重拳、腿踢、空中招来了不硬挡（薄挡）—— 能勾就勾，不能勾就往后冲刺退开；对空用挑掌；压起身快招贴上去。
- 满级的螳螂少主动起手（`M_AI.open`：低档 1.15 快打快走，满级 0.55）、不拿崩捶迎冲过来的人、不拿劈掌 / 低勾踢 / 低搂开路（量过：满级对满级这三手最亏 —— 8 帧的起手被看见就罚）、断了的一串不接（他不在硬直里就别从站着起劈掌）、少跳。
- **一到跟前就出手的人**（一直按拳的木头；`jabHappy`：贴身那一档 10 帧内出手的机会 × 记得准不准 > 0.6，按档打折 `M_AI.standOff`）：难以上的螳螂不站在他拳底下 —— 站在他拳的射程外一点（`oppJabReach` + 8 ～ 16），他跑进来不迎上去、进了他的射程先举手，自己收完手不蹦就先举着。量过：没有这一手，终极螳螂蹦出去又跑回他拳底下站着，一直按拳的木头打掉四成多；有了 17%。
- 打螳螂拳的电脑：它薄挡 —— 对着挡着的螳螂多出重拳、腿（`M_AI.vsHeavy`；难以上多用腿：重拳 10 帧起手，伸着手的螳螂一勾一个准）；它爱勾 —— 老被勾住就少出手上的招的前摇长的（`memo.ctr.hand`，勾住和被咏春拉住一样记）、多蹲（站着的勾抓不到蹲着的）、多出腿；它停手就罚（本来就会：挡住以后罚收招，气短的收招更长、更好罚）；挂手 / 挂捶是收势、取消不了的招被挡住了也罚。习惯表里螳螂的起手三类（`mfast` 快手、`mkick` 腿、`mhook` 勾）。

## 六、平衡（NOTES「3.3」「查平衡」3.3 有完整的数和调的过程）

目标和前三派一样：同一档电脑对电脑两派打掉的血一半上下，木头玩家打螳螂拳的电脑六档和格斗术差不多难（入门 ≥ 75%、简单 ≥ 55%、中等 30 ～ 65%、困难 15 ～ 50%、终极 8 ～ 35%、满级 ≤ 25%），满级对满级上限的形状照 Jack 定的：咏春最高，螳螂第二，格斗术、太极在后。

量出来（3.3.0 定稿）：
- **满级对满级**（16 个种子 × 4 回合，左右轮着站）：螳螂打格斗术 50.7、打咏春 48.7、打太极 46.1；六边形里的上限（对三派平均）50.4 [48.3, 52.6] —— 咏春 54.2 最高，太极 52.5、螳螂 50.4 挨着，格斗术 44.6。

## 七、动作（照参考图，侧面朝对手）

- 待机（`ref/mt_stance.png`）：弓步，前腿弓、后腿蹬直，身子往前倾一点；前手勾手（螳螂手：手腕折下来、指尖捏在一起朝前下）伸在胸前、肘微弯；后手举过肩、肘弯着、勾手指尖朝下；头带的带子甩在后面。呼吸两秒一口气，两只勾手一上一下微微颤（螳螂的手在动）。
- 崩捶：前手从勾手张开成拳、拳背往前一弹（拳心朝下），身子不动、只送肩；翻车：后手从上往下一劈再翻上来。
- 劈掌：掌从头顶劈下来，身子跟着往前压；砸捶：拳从头顶砸到胸口高。
- 勾踢：前腿提膝、小腿往里一勾（脚尖勾着）；蹬扑：脚底板往前蹬；低勾踢：蹲下前腿贴地往里勾。
- 勾搂：前手勾手往前一探、一勾、往回一带（勾住的时候手搭在他小臂上：和咏春的别手一样，手真的贴在他胳膊上）。
- 蹦步退：两脚一蹬往后一蹦，两手还架着。
- 挡（封手）：两手勾手竖在胸前，像两把刀；蹲着的挡两手往下封。
