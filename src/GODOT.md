## 已经定下的技术选择

- **Godot 4.7.2 稳定版、普通版（不是 .NET 版）、GDScript。** C# 版导不出网页版。Claude 的工作区实测过：从 GitHub Releases 下载 Linux 版能跑（`--headless`）。Jack 电脑上也装同一个版本（godotengine.org 下载 Windows 普通版，解压双击就能用，不用安装）。
- **渲染器**：桌面 Forward+，网页版 Compatibility（project.godot 里 `rendering_method.web`）。
- **网页版导出用单线程**（GitHub Pages 设不了 COOP / COEP 头，多线程版跑不起来）。导出要「导出模板」（GitHub Releases 上那个 `.tpz`，一个多 G），Claude 在工作区下载。
- **放在哪**：仓库里新建 `godot/`（项目源码，全是文本文件：`project.godot`、`.gd`、`.tscn`、`.tres`），导出的网页版放 `godot-web/`，网址 https://jax1ng.github.io/Modou/godot-web/ 。现在的网页版（根目录 `index.html`、`src/`）一点不动，照常能玩。claude.ai Project 里也存一份 `godot/`（和 `modou/` 一样，二进制文件只放仓库）。
- **版本号**：Godot 版从 **3.0.0** 起（NOTES 的规矩：引擎换了、存档和联机跟 2.x 整个不兼容 = 大版本）。搬家途中用 3.0.0-alpha.N。之后照 NOTES 的大.中.小走。
- **只更新软件版**（2026-10-27 Jack 改的规矩，替掉 NOTES 2.8 起的「只更新网页版」）：每次改完打 Windows 版（`godot/tools/build_windows.sh`，Forward+）发给 Jack；网页版（`godot-web/`）停在 3.0.0-alpha.3 不再导出。软件版还不能联机，要联机暂时还用那个网页版（两边版本号得一样）。

## 架构：判定和画面完全分开

现在的 JS 版本来就是这样（战斗逻辑不碰骨骼、画面、随机数，见 NOTES「改代码的规矩」第 3 条）。Godot 版照搬这个分法：

- **逻辑层（sim）**：纯 GDScript 类（`RefCounted`，不挂在场景树上），不用 Godot 的物理引擎、不用 `Area3D` 碰撞。一秒 240 步（`SIM_HZ`）、一帧 4 步，和画面帧率无关 —— 跟 2.6 起的 JS 版一模一样。坐标还是 JS 那套：横向 `x`、离地 `alt`，场地 1600 宽。射程、判定都按 JS 的规则算（`reach` 是两人中心距），**和 3D 模型长什么样无关**。
- **画面层**：3D 场景每帧读逻辑层的状态画出来，在两步之间插值（像 JS 的 `RA`）。逻辑坐标 → 3D：`x` → X、`alt` → Y、Z 固定（转身 `spin` 只是画面）。比例 **1 像素 = 0.012 米**（人高 146.45 → 1.76 米，和 Mixamo 一类的模型一样大，以后换模型不用缩放）。
- **动作**：先保留 JS 的整套姿势系统（`pose.js` 的姿势参数、`moves.js` 的关键帧、`fighter.js` 的 `fk()` 算出每个关节在哪），再用 IK 让 3D 骨骼对上这些关节位置。这样 44 招的动作数据一个不丢、手感一样。以后要更细的动作，再换成做好的动画片段（AnimationPlayer）。
- **临时小人**：Claude 用 Blender 脚本做一个低多边形人，绑 **Godot 标准人形骨骼**（`SkeletonProfileHumanoid` 的骨头名）。以后 AI 生成的模型（Meshy / Tripo / 混元）只要也映射到这套骨骼（Godot 的骨骼重定向），动作直接套上去。

### 联机要「两边算得一模一样」—— Godot 里的坑

- GDScript 的 `float` 是 64 位，和 JS 的数一样 ✓。但 **`Vector2` / `Vector3` 是 32 位的**：逻辑层里一律不用向量，用一个个 `float`。
- GDScript 的 `int` 是 64 位，JS 的位运算是 32 位：输入位、`stateHash()` 这些位运算要自己 `& 0xFFFFFFFF` 截成 32 位，不然和 JS 对不上（对照测试会查出来）。
- 不用 `sin`、`pow` 这类函数（NOTES 第 3 条，照旧）；不用 Godot 自带的随机数做逻辑 —— JS 里自己写的随机数（`srnd`、`vrnd`、`LIVE_R`、AI 的种子）原样搬过来。
- 存档 / 读档（回滚用）：每个类自己写 `save()` / `load()`，`SNAP_SKIP`、`GAME_KEYS` 照 JS 的意思搬。

### 怎么证明「搬得一模一样」

用 JS 版当标准答案：同一串输入（固定种子、电脑对打几局），JS 版每 N 步记一次 `stateHash()` 和关键字段，Godot 版跑同样的输入逐步比。第一个对不上的步就是搬错的地方。JS 版的 `tests.js`（202 条）也一条条搬成 Godot 的无界面测试（`godot --headless`）。

## 分几步搬（每一步都能在网页上玩到点东西）

1. **搭架子**：`godot/` 项目、网页版导出流程推到 `godot-web/`；场景里一个方块地面 + 两个临时小人站着。
2. **逻辑层**：config → pose → moves → input → fighter → combat → game（回合、胜负），无界面跑通，用上面的对照法对上 JS。
3. **画面**：临时小人 + 动作、镜头（`ZOOM`、跟着自己、对手出画箭头）、血条气条、计时、印章飘字、打击特效（先做主要的）。到这一步能两个人本地对打。
4. **模式和界面**：菜单、人机（ai.js 五档）、双人、训练场 + 破招练习（drills.js）、设置、键位（三套、冲刺怎么按）、人物颜色、教程（guide.js）。按钮写「确认」不写「好了」。
5. **场景**：五张水墨山水 + 练武场，先把 JS 画的背景搬成几层 2D 贴图放在 3D 人身后（视差、动起来的背景照旧）；以后再换成 3D 场景。
6. **声音**：JS 是现算的（战鼓、镲、古筝 Karplus-Strong、木鱼……），Godot 里用 `AudioStreamGenerator` 现算，或者开局时算好存成音频。
7. **联机**：Godot 网页版自带 WebRTC；但 JS 用的 Trystero（Nostr 公共中继找人）没有 Godot 版，房间码找人这一层要自己写（同样的 Nostr 做法，或者别的信令）。回滚、二进制输入包、中继（TURN，Jack 的 Metered 账号）照 net.js 搬。这块最难，放最后。Godot 版和 JS 版不能互相联机。
8. 以后（搬完再说）：换 AI 生成的正式人物模型、定美术风格（Jack 喜欢颜色鲜艳的）、3D 场景、桌面版 / Steam（GodotSteam）。

动作台（poses.html）、平衡报告（balance.html）这些工具先不搬，需要时还用 JS 版的。

## 正式人物模型（AI 生成的）

Jack 出模型的流程：GPT 照原画出一张 A 字站姿的建模参考图（手臂离开身体、劲装、没有飘带长袍）→ Meshy 生成（智能拓扑 / 重拓扑到 3 万面上下、四边面）→ 绑骨（人形、Mixamo 骨架）→ 下载 GLB（Mixamo、单个文件），发给 Claude。Claude 这边：

1. `python3 godot/tools/import_char.py 原文件.glb godot/assets/chars/名字 名字`：拆出网格 + 蒙皮（去掉贴图、动画）、贴图碎块之间的黑底填上旁边的颜色存 4K / 2K 两张 JPG、两只手各加三节「握拳骨」（Meshy 的骨骼没有手指）。
2. 贴图的导入设置：4K 用 VRAM 压缩 + 高质量（桌面版）；2K 用有损（网页版，下载小、手机浏览器也能用）。export_presets 里网页版不带 `*_4k.jpg`、桌面版不带 `*_2k.jpg`。
3. `godot/view/char_model.gd` 的 `MODELS`、`LOOKS` 加一行：哪个人物（侠 / 僧）、哪身颜色用它，放大多少（`scale`：和简易模型一样高）。
4. 看效果：`tests/render_model.gd`（各个姿势、全部招式拍图）、`tests/shoot_variants.gd`（真的场景里拍，查画面问题）、`tests/model_info.gd`（量出来的身材和简易模型比）。

接法（`view/char_model.gd`）：动作还是原来那一套（FighterAnim / Rig 算关节，招式数据一个不动）；模型的每根 Mixamo 骨头跟着 Rig 的一根骨头走 —— 模型站姿时先按 Rig 的规矩算出「这个姿势下 Rig 该是什么样」，记下模型骨头相对它的偏差，以后每帧照着摆；模型自己的身材（骨头多长、肩多宽、脚踝多高）量成一个 BodyDef 交给 FighterAnim，拳脚够得着、脚踩在地上。骨骼是「平的」（没有父子关系），胳膊腿顺着骨头伸缩一点正好接上。
