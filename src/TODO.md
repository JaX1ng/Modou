对照：2.7 定的规矩是乱换招的木头 入门 ≥ 80、简单 ≥ 65、中等 ≥ 40、终极 ≥ 20（困难两成半上下）—— 这是「乱换招」量的；换成最笨的「一直按拳」，困难一档三派全输，格斗术的电脑连终极都被格斗术一直按拳打成 12:0（一回合 25 秒）。

**原因**（看逐帧记录）：
1. 电脑看招要 react 帧（困难 9、终极 11），咏春冲拳前摇 4.25、短拳 5.5 —— 看见的时候拳已经打到了（eta < 0），所有「看见出招 → 卸力 / 捋 / 接招 / 读招」的路全走不到，只剩「挡」这一条（挡还要掷骰子：困难 0.66）。终极、满级靠的是「瞬间看穿」（1 帧看穿，非人），所以终极的太极还顶得住，困难的顶不住。
2. **挡住一下以后就按键**（格斗术最严重）：挡住短拳第一下，电脑看见的还是 9 ～ 11 帧以前的「他在收招」，就出 5.5 帧的拳去罚 —— 可他早已取消接了第二拳（连珠快拳拳拳取消，缝只有 5 帧），回回被打断，接着吃一整串（短拳 → 快拳 → 快拳 → 连珠左右 → 寸劲 18，一串 55；寸劲收招有十几帧空，可电脑只罚挡住的、打空的招，挨了打以后他的收招从来不罚，爬起来又进下一串）。
3. 太极的电脑把「捋」当格斗术的卸力用（看见出招、还来得及才按），对 4 帧的拳永远来不及，也不会按节奏预判；被连环冲拳打中以后走的是「一直按着挡」那条（noParry = true，顺手把捋也关了）。起身那几帧默认什么都不按（只有防跳进来才先举手），压起身的拳回回打在站起来的头几帧上。
4. 规则本身顶得住：写一个只会「按住挡、每 26 ～ 40 帧按一下后、捋住了接 重重」的脚本太极，打一直按拳的咏春 12:0（木头只打掉 0 ～ 40%）。**所以不是太极弱、不是咏春强，是人机弱** —— 而且不只太极。
5. 真人的太极另有一个坑：按后只在「挡着」的状态里记（`tjInput` 的 neutral），挡住的硬直（blockstun）里按、松都不算；连环冲拳一拍 8 帧、挡住硬直 7.5 帧，两拳之间「挡着」只有半帧 —— 要捋只能按住后跨过那半帧，按早了 / 短了都白按，说明书上也没写。
