### 1. 咏春拳的挡：三个键改成「一错、一平、一对」；搭手的缠绕再精致一点，不要上下扭

Jack 说的：咏春的挡太复杂，只有唯一解。应该是三种（他记得的没错 —— 按住挡再按 拳 / 重 / 拿，三选一；2.11 是一对两错）。改成：一种错、一种平、一种正确的反击 + 高收益。咏春拳手互相博弈缠绕的模型做得再精致一点，但别像蛇一样上下扭 —— 那是 z 轴上的事（里 / 外、前 / 后），必要时加一点阴影就行。

我的判断：

- 现在：对面出一招，三个键里只有一个接得住，另外两个都 ×1.3（`WC_WRONG_MUL`）。猜错就挨重罚，所以下限低（第 8 条他说的）。
- 改成一个环：**拳 → 重 → 拿 → 拳**。按它本身 = 对（接住），按环上的下一个 = 平，按上一个 = 错。
  - 对面出拳系的手上招：按拳 = 对（拍手 / 摊手，进搭手、顺 3，照 2.11）；按重 = 平（膀手转马把拳带开 —— 当普通挡住：吃三成、不进搭手、不加罚）；按拿 = 错（弯腰去按腿，脸上挨一拳 ×1.3）。
  - 对面出重系：按重 = 对；按拿 = 平（按手把重拳压下去）；按拳 = 错（拍手、摊手被重拳压穿）。
  - 对面出腿：按拿 = 对；按拳 = 平（拍在腿上，挡住了）；按重 = 错（转马转到腿上）。
  - 另一种分法（按武术道理，不成环）：拳 → 重平、拿错；重 → 拿平、拳错；腿 → 重平、拳错。没有环好记，Jack 挑。
- 「平」就是普通挡（吃三成、`bstun` 照旧、不进搭手），画面上照样摆出按的那一手（看得出按了）。挨打硬直里接（黐手破连）同样按这个环算。时机不对（按早了、在收手时挨打）照旧算错 —— 时机是操作难度，留着。接不住的那几类（擒拿、下段的拳肘、坠山、大招、顺 3 以上的连环冲拳、推挡）照旧 ×1.3，这是它的弱点；要是 Jack 觉得太狠，坠山、大招、推挡可以改成平。
- 瞎按三选一的期望：以前 1/3 对 + 2/3 ×1.3，现在 1/3 对 + 1/3 平 + 1/3 ×1.3 —— 下限抬上来，读对了的上限一点不变。
- 缠绕的样子（搭手里的手型 `W_SHAPE` 摊 / 膀 / 伏、翻手 `W_ROLL`、咏春打咏春 `touchFlip`）：手型换位只在里 / 外（z）和前 / 后上走，两只手一直在胸口到肩那一段高度，不上下翻；里外靠 2.10.1 那套「远侧那条淡一点点」（`shade.far` / `farJoint`）分，换位那一下两条小臂交叉时阴影跟着换边；肘一直朝下。做完截图给 Jack 看，他点头了再算完。

### 2. 拉手跪马：被拽倒的人要趴在地上，发带往前倒

Jack 说的：人物倒下去的模型不对 —— 看着是按发带落在地上判的，人物悬在空中。要人物趴在地上，发带往前倒就行。

我的判断：

- 趴姿 `POSE.lieProne`（pose.js：rot 90，两手撑在头前面的地上）—— 整个人转了 90° 以后身子的厚度和撑着的两只手把躯干架起来了，所以浮着；发带从头上垂下来正好挨着地，看着就像是按发带对的。2.0 的躺姿（`lie` / `lieFlat`）当时就定过「身子、腿、头都躺在地上，可以穿地一点点；不是按发带和地面重合来判断」，趴着照同一条做。

- 测试：趴着的每一帧身子剪影最低的那一圈（头、胸、髋、膝、脚）离地都在 -2 ～ +2 以内，不只查头。只是画面。

### 8. 平衡：最高级别的检测；同派招的数值拉开、跨派平衡；咏春上限高、下限略高

Jack 说的：优化到最高级别的游戏平衡检测模式，包括同门派内的招数数值和不同门派之间的强度平衡。现在总感觉咏春偏弱。要保证操作难度的同时上限高、下限略高就行 —— 现在下限太低（所以挡改成一错一平一对）。另一个比较严重的问题：招数之间数值拉不开，玩家觉得乱玩都行，反正收益没啥区别。拉开数值的同时要兼顾平衡。

我的判断：

- 「检测」：`balance.html` 现在只算传统格斗。扩成四块：
  1. 中立收益矩阵、起身攻防：传统 vs 传统、咏春 vs 咏春、传统 vs 咏春（咏春的选项：拳、重、踢、拿、听劲 + 三个键、标指、截脚、转马……）。
  2. 分层玩家：木头（乱按）/ 中等 / 终极 / 满级（第 5 条），两派两两对打各跑 N 局 —— 下限 = 木头咏春打木头传统，上限 = 满级咏春打满级传统，中间两档看单调不单调。目标：下限 45% ～ 52%（Jack：略高就行），上限 ≥ 50%。
  3. 「数值拉得开」怎么量：每个距离上均衡里最好的选项和随便挑一个的平均差多少血、最差的亏多少 —— 挤在一两滴血里就是「乱玩都行」；同一系里高级招 / 连招后半的收益比普通招 ≥ 1.5 倍，反打、破招、接住的收益 ≥ 中立起手 ×1.3（这条 2.6 定过「至少多三成」，再查一遍）。
  4. 一招一张表：伤害、前摇、风险（打空、被挡罚多少）、收益；报告里标出「收益差不多、风险也差不多」的那几对招 —— 要拉开的就是它们。
