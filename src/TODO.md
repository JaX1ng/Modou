### 4. 咏春拳的挡重做：长按是「等着接」的架势，对面打过来时按键接招

Jack 的键位：拳 J、重 K、踢 L、挡 I、拿 O（下面按动作名写）。参考图 `ref/wc_guard_1.png` ～ `wc_guard_5.png`：五张打木人桩的防守架势（Jack：「以上这五个图片是防守架势」）。

Jack 说的：

- 长按挡的时候，手臂不动，只是往后收一点（不是现在那样一直翻盘手）。
- 对面打过来的时候，才触发这五个动作（轮着来）。哪张图是什么动作他不清楚，让我自己判断。
- 他真正要的：**长按本身就是打** —— 长按挡的同时按拳 / 重 / 拿，触发这五个不同的动作，去克制对面不同的招。这套克制和平时拳 / 重 / 踢那个三角不是一回事，接对了能让对面陷入比普通挡住、卸力更被动的状态。
- 接轻拳、接重拳、接踢，动作上要有细节、要分得开，不是一个动作接所有。
- 削弱咏春拳自己平时的拳 / 重 / 踢，但要平衡。
- 重点放在「长按之后的反击」—— 像图里打桩那样，反击、细节上的攻击。咏春拳就是一个很吃操作的角色。

我的理解（开工前和 Jack 对一遍，定了写进 `WINGCHUN.md`）：

- 长按挡 = 「听劲」架势：问手护手往胸前收一点，不翻手、不动，可以慢慢走（现在的 `WC_WALK`）。只举着不按键：按现在的规矩普通挡住（三成伤害），**不进搭手**、没有别的收益 —— 不按键就不赚，逼着你读招。
- 对面的招（正面、中上段的手上招和腿）打进来那一刻，按住挡再按拳 / 重 / 拿 = 接招：按对面是什么招，接出一个桩法。五张图分给 拳 / 重 / 拿 × 轻拳 / 重拳 / 踢 这几种情况，哪张图配哪种做的时候我定，大致：接轻拳的快、小（拍、摊一类）；接重拳的吃劲再转（膀、耕一类）；接踢的用低手；按拿是搭上手扣住、直接进搭手。
- 接对了：对面硬直比被挡住 / 卸力长得多，失衡或者被黏住，自己顺一上来就 2～3 级起手接一套（像现在反打的待遇）。按错键（按了接拳的可对面是踢）或者时机不对：挨打，吃的比没举手还多一点（像现在黐手破连读错 ×1.3）。
- 时机窗口像现在拍手那样卡在对面判定帧前后，多宽做的时候量：困难档的人按得出来、入门按不出来才对。
- 和 2.10 的黐手 / 搭手怎么接：黐手「黏住就进搭手」改成「接对了才进」，搭手里的翻摊膀伏、从手型里打、拉手照旧；拍手（点一下）、耕手、黐手破连都是「对面打过来时按键」这一类，合并进这一套，别留两套差不多的东西。
- 削弱平时的拳 / 重 / 踢：中立主动起手再打折（现在 ×0.8，往 ×0.7 上下试）或者头两拳的空再大一点；具体数做完跑平衡报告和电脑对打定，两派还是一半上下。
- 电脑：咏春拳的电脑要会用这套（按难度读招接），打咏春的电脑要会骗接（空挥引你接错、多打下段和擒拿）。
- 测试、教程「咏春拳」那本、动作台分组一起改。
