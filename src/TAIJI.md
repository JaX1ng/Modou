## 一、一句话：蓄 · 化 · 发 · 捋

- **慢**：站着出的起手全是慢招（前摇 18 帧起；金鸡独立对空除外），没有快招抢先手。对面看得见、挡得住每一招 —— 太极不靠快打中人。
- **蓄**：拳 / 重 / 踢按住不放，出招走到前摇的六成（`TJ_HOLD_AT`）停住，势接着一式一式往下走（揽雀尾 掤 → 捋 → 挤 → 按，搬拦捶 搬 → 拦 → 沉，蹬脚 提膝 → 分手）；每 `TJ_SEG` 帧劲 +1，最多 `TJ_JIN_MAX`（3）级，蓄满 `TJ_CHARGE` 帧自己发。蓄着不能走、不能转身、不能取消。
- **发**：松开 = 从蓄着的样子直接打出去（再走前摇剩下的四成，七帧上下）。伤害 ×(1 + `TJ_JIN_DMG` × 劲)；劲 2 打倒，劲 3 把人发出去一丈远（`TJ_FA_KV`）。挡住了不推远：慢招被挡住照样罚得出来。
- **掤 · 化**：手上的招（揽雀尾、搬拦捶两家，连同它们的势）前摇的**后一半**（第 `TJ_PENG_FROM` 帧起）身上有掤：正面打过来的拳掌、中段上段的腿被化掉 —— 只吃 `TJ_HUA_KEEP`（两成半）、不进硬直、招照样打出去、劲 +1；这一招打中 ×`TJ_JIELI_MUL`（借力打力）。蓄着的时候也有掤。
  - 化不了：擒拿（擒拿克掤）、下段、跳起来打的、坠山、推挡、大招、劲大破得开的（pierce，咏春的寸拳）。
  - 一招只化 `TJ_HUA_MAX`（2）下，第三下就破了（连打破掤：传统格斗的拳拳拳、咏春的连环冲拳第三拳）。
  - 前摇的前一半掤还没撑起来，一拳就打断 —— **要先出，别等他出手了再出**（看见他出手再出化不着：这是「慢」在操作上的体现）。
  - 腿上的招没有掤（`noPeng`：单腿站着掤不住，起腿的时候挨拳照样失衡）。
- **捋（引进落空）**：按住挡，他打到之前 `TJ_LU_WIN`（6）帧里按一下后 = 捋住：不掉血，他被牵到你身后 `TJ_LU_GAP` 远（`TJ_LU_PULL` 帧带过去），背对着你失衡 `TJ_LU_STUN` 帧，劲 +1，你先打（打中 ×`TJ_LU_MUL`，「引进落空」；比卸力反击的 `PARRY_MUL` 低，劲另算）。太极拳没有卸力，捋就是它的卸力：两次按后隔不到 `TJ_LU_LOCK` 帧没有捋（防乱按）；捋不了的和化不了的一样。身后是墙：他贴着墙，你往前让一步。
- **采**：抓住以后 拳 = 挒（两下肘靠，放开你先动）、重 = 野马分鬃（摔：从身前掀出去，落在你前面，不换边）、踢 = 采住蹬脚（打倒）、不按 = 按（推开）。他出腿的时候采 = 接住腿，搂膝拗步（打倒，挣不脱）。
- **劲**（太极拳唯一的资源，头顶上几个墨点）：蓄满一段、化一下、捋一下 +1；这一招判定出来那一下用光（打空也没了）；挨打一下散光；放着不用 `TJ_JIN_KEEP` 帧掉一级。

## 二、难度和上限（Jack：像王者的妲己 / 露娜，每一派有自己的操作难度和上限）

- **格斗术**（3.1 以前叫传统格斗）：中等难度，上限在读招破招。
- **咏春拳**：最难（按拍子、接招按对键、搭手），上限最高。
- **太极拳：上手容易、上限中等**。慢、看得清、不用按拍子；新手乱按，对面乱打打进掤里白送劲。难在：什么时候先出（掤要提前撑）、蓄多久再松（他走进来就松、他不动就蓄、他要抓就别蓄）、捋的时机（六帧）。打它的办法很清楚：抓、打下段、跳着打、连打三下破掤、退开等它发空。

## 四、引擎里改的（每一派都能用，太极先用）

- 输入：拳、踢也记「按住」（`JAB_HOLD` / `KICK_HOLD`，一帧 15 位，联机照旧 16 位；`HELD_MASK` 跟着猜）。
- `applyHit`：挨打 `B.jin = 0`；`guard()` 里 `slowGuard`（太极拳的慢拳被挡住照重招算：推得近、收招长）。
- `separate()`：被捋过去的那几帧（`luPull`）不推挤。`REEL_LABEL.lu = '引进落空'`。
- `record()`：`tjc`（在蓄）、`tjp`（身上有掤）、`jin`，给电脑看。`SNAP_SKIP` 加 `lastFlowPose`（只是画面）。
- 钩子：`input`（'neutral' 记按后、劲慢慢散；'attack' 蓄势 / 发劲 / 采住以后；'parry' 捋了以后）、`defend`（化、捋）、`strike`（发劲的倍数、打倒）、`grab`（搂膝拗步）、`target`（蓄势一式一式走、松开从蓄着的样子打出去、云手、捋）、`drawCue`（劲的墨点、蓄势的墨圈）。

## 五、电脑（`KITS.taiji`；两边智能性相等）

- 太极拳的电脑：站在自己射程边上等（`desire`）；他朝我走过来快进射程就先出一招按住蓄，他走进来 / 收招 / 挨硬直就松开（`tjKeepCharge`，看得懂的松得准）；化掉了一下马上发（借力打力）；看见他打过来、来得及就先出一招等他打进来（`tjReact`，`TJ_AI.hua` × 读招的本事 —— 太极拳的「读招」）；捋和传统格斗的卸力是同一个本事、同一个机会（挡的时候正好快打到了才捋；看穿了的在 `hellCounter`，分量照卸力）；捋了以后 搬拦捶接双峰贯耳 / 揽雀尾三下 / 蓄一段的揽雀尾（`tjHoldFrames` 按他还剩几帧失衡算蓄几段）。
- 打太极拳的电脑：看见它出有掤的招（`tjp`），改抓、打下段、退开（`vsPeng`，`TJ_AI.vsRead` × 读招的本事）；看穿了的（`vsPengOpts`）把往掤里打的那几手去掉，留下擒拿、下段、卸力、闪身、挡、退开；它蓄着（`tjc`）够得着就抓 / 打下段、在它射程边上就退开等它发空（`vsCharge`）；习惯表里太极拳的起手是三类（`tpeng` 有掤的慢招、`tkick` 太极的腿、`tlow` 下势）。

- 3.1.1（Jack：困难、终极的太极拳打不过一直坠山击、飞踢）：太极拳的招前摇 18 ～ 22 帧，一直跳的人一跳就越过去、从天上打下来。现在起慢招之前看他会不会跳过来（`slowOK`：他每一帧起跳的机会 `memo.jz`、我起慢招的时候他跳了几成 `memo.jr`），一直跳的人面前少出、先举手等他跳过来接（金鸡独立按真的轨迹算，`aaCatch`）；蓄着的时候看见他蹲下起跳、在天上就松开挡（`tjKeepCharge`）；他爱坠山就少按金鸡独立。一直跳进来（打中接一整套）的人打掉的血：困难 52 → 30%、终极 45 → 21%。一直**坠山（海底针）**还是七成多 —— 太极拳的拳迎不上坠山、挡住了够不着，要改规则（NOTES「待做」三个想法，等 Jack 定）。
