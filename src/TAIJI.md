## 待定（要 Jack 定的）

## 一、底子

- **每一派自己的按键语法**：和咏春一样走拳派的钩子（`input` / `defend` / `clash` / `grab` / `target` / `drawCue`……），不往通用代码里加「如果是太极」。太极自己的文件（`js/taiji.js`），招名带 `t` 前缀，底子 `TBASE`（单鞭的架势）。
- **劲是太极唯一的资源**（0 ～ 3，像咏春的顺）：化掉一下 +1、捋到一下 +1、蓄势走一段 +1；发劲一下花光；挨了打（没化掉的）清零；打空不清。劲到 3 头上冒一个「劲」字（像顺）。
- **三角照旧**：拳 / 重 / 腿 / 拿 / 对空 / 空中 / 必杀的系别和别的派一样比（掌系是拳系、捶系是重系）；打击克擒拿、擒拿克格挡、格挡克打击 —— **擒拿克掤**：太极化得了打，化不了抓，这是它的弱点（和「擒拿克黐手」对应）。
- 太极没有卸力（`parry: false`）：捋就是它的卸力（第四节）。挡住的硬直里按拳不是推挡、是挤（第十一节）；按重是靠（花气，像截击）。

## 二、五个键（站着的时候）

- **拳 = 掌**：揽雀尾（掤 → 按）。按下去先掤（起手），接着按（双掌发劲往前推）。按住不放就是蓄（第三节）。
  - 前 + 拳：玉女穿梭（上步穿掌；射程长、前冲大）。
  - 后 + 拳：倒卷肱（退半步出掌；拉开距离用）。
  - 蹲 + 拳：下势（蹲身穿掌，下段）。
- **重 = 捶**：搬拦捶（搬 → 拦 → 捶）。按住 = 蓄；松开 = 捶（发劲，重系，前摇里整段都有掤）。
  - 前 + 重：撇身捶（转身横捶，射程最长）。
  - 后 + 重：肘底捶（退半步、贴身短捶）。
  - 蹲 + 重：金鸡独立（提膝、手往上托，对空）。
- **踢 = 蹬脚**：提膝（起手，样子是金鸡独立的前半）→ 蹬出去（脚跟，中段，腿系，射程最长）。按住 = 蓄。
  - 前 + 踢：分脚（脚尖，射程比蹬脚再长一点、伤害低一点）。
  - 蹲 + 踢：跌岔（陈式：沉身一坐、腿扫出去，下段、打倒）。
- **拿 = 采**：抓住以后（擒住，叫「采住」）按：拳 = 挒（扭住胳膊一挒，短打、失衡）、重 = 靠（肩靠，打飞）、踢 = 采住蹬脚（踢开，打倒）、拿 = 野马分鬃（摔：斜着把人掀出去，落地三个身位外；代替过肩摔，不换边）。采住腿（他出腿时按拿）= 搂膝拗步（搂住腿、上步一掌推出去，打飞）。蹲 + 拿 = 搂膝（抄腿：接地上的腿，抓蹲着的人）。
- **挡 = 掤**：见第四节。
- 气满 重 + 踢 = 如封似闭（大招，待定 5）；挨打时 重 + 踢 = 爆气；冲刺 = 进步；跳起来：白蛇吐信 / 进步栽捶 / 旋风脚 / 海底针（坠）。

## 三、蓄 · 化 · 发（操作核心，待定 1 的甲）

一句话：**按住不放，势就慢慢走；走得越远，松开那一下越强；走势的时候身上有掤，对面这时候打过来是化不是挨。**

- **慢**：全派都是慢招 —— 掌系前摇 18、捶系 22、腿 22（基准帧，换算完再 `slow` 拉到位），没有一招快过 18。按 2.12 的标尺，对面反应 15 帧看得见、挡得住每一招。所以太极不靠快打中人。
- **蓄**：拳 / 重 / 踢按住不放，前摇走到「待发点」（六成处）不松开，势就接着走，身上的动作是套路一式一式往下走：
  - 掌：掤 → 捋 → 挤（三段，各 12 帧）→ 松开 = 按。
  - 捶：搬 → 拦 → 蓄捶（拳收到腰后）→ 松开 = 捶。
  - 腿：提膝 → 独立 → 蓄 → 松开 = 蹬。
  - 走完一段 劲 +1（最多蓄三段 = 36 帧，劲 +3）；走到头自动发。蓄的时候不能走、不能转、不能取消（挨打会被打断：和咏春蓄劲一样，蓄的时候挨打就是挨打 —— 除非化得了，见下面）。
- **化（掤）**：出招的前摇里和蓄势里，身上有掤：对面这时候正面打过来的**手上的招、中段上段的腿**被化掉 —— 我吃两成、不进硬直、不掉势，劲 +1，他的那一招照样走完（他不失衡）。**化不了**：擒拿、下段的拳脚、空中的招、大招、推挡、爆气 —— 这几样打蓄势的人就是打着。和咏春接不住的那几类一样，打太极就多抓、多打下段、跳着打。
- **发**：松开那一下 = 发劲。伤害 = 这一招的伤害 × (1 + 0.2 × 劲)，击退跟着劲长：劲 0 ～ 1 普通击退；劲 2 = 打飞（像被腿顶翻那样翻滚回去两三个身位）；劲 3 = 发人丈外（一直飞到墙、撞墙倒地）。打中挡着的人也推得远（劲 3 推到墙），只吃三成。
  - **借力打力**：化掉一下以后 8 帧以内松开 = 这一下 ×1.3、他硬直多 5 帧（像挡后反击的待遇）。先化再发是太极最赚的一手。
  - 劲 2 以上的发劲，咏春接不住（举手接 ×1.3，和接大招一样）、传统格斗的霸体吃不住、卸力卸得了（但要卡 6 帧的时机 —— 蓄多久松开他不知道）。
- **虚实**：蓄的意义在时机不定 —— 对面不知道你哪一帧松开，卸力卡不准、看招再挡也得一直举着。他能做的：抓（擒拿克掤，蓄着的人跑不了）、打下段、跳起来打、退出去等你打空（打空的收招长，破绽 ×1.25 照旧）。你能做的：看他抓就松开（发劲打击克擒拿 —— 打到他之前他的擒拿先到就被抓）、看他蹲就换上段、看他退就不发了（蓄到头自动发，所以蓄到第三段之前得决定）。
- **这一派的连招短**：一个势最多三下（第六节），打中了接下一下也是慢的（前摇 18），靠的是硬直长、击退远，不靠快。
- **乙、丙两案是什么样**（待定 1）：
  - 乙 引进落空：出招照旧慢但没有蓄、没有掤；整派靠捋（第四节）把人引进来（他栽到你跟前、背对着失衡），然后发劲。收益全在防守反击上 —— 和咏春的接招太像，只是键不一样，不推荐。
  - 丙 势：按一下拳就是一整套揽雀尾四手（掤捋挤按）慢慢打完、中间不能停、整套霸体，第一下掤到了后面三下跑不掉；重是搬拦捶三下、踢是提膝蹬脚两下。慢而且整套打，看着最像太极；缺点是玩家按一下看十几帧动画，中间没得操作，和「操作有特色」反着来，不推荐。

## 四、挡：掤、捋、靠

- **按住挡 = 掤（十字手）**：普通挡，吃三成，有挡住的硬直，站挡蹲挡照旧。按着前 / 后走 = 云手（边挡边走的动作换成云手，手在身前画圈；速度和别人的边挡边走一样）。
- **捋 = 引进落空**（待定 8）：挡着的时候，他打到的前 6 帧按一下后（像卸力的时机）= 捋住 —— 他那一下的劲被引空：我一点不掉血、不进硬直，**他被牵得往前栽到我跟前、背对着我失衡**（像挨了回身肘那样踉跄 32 帧、面朝着原来的方向），我先动、劲 +1。捋得住的和化得了的一样（手上的招、中段上段的腿），擒拿、下段、空中招、大招捋不住。两次按后隔得太近没有捋（防乱按，和卸力的 24 帧一样）。
  - 捋完接什么：他背对着失衡在我跟前 —— 采（采住接一套，他背对着拆不了）、发劲（这时候劲至少 1，再蓄一段打飞）、顺拦肘。
- **挡住的硬直里**：按拳 = 挤（像推挡：把他推开、不掉血）；按重 = 靠（肩靠，花 25 气，出手前几帧打击无敌，像截击；打中打飞）。
- 按着挡朝他双击 = 斜飞（闪身，只躲得过重系的手上招，躲过了自动闪通臂）。

## 五、采（擒拿）和摔

- 采：和擒拿一样的判定（前摇 6、射程 84），抓住 = 采住（擒住）。后续见第二节。
- 野马分鬃是太极的摔：采住以后按拿，侧身一转把他斜着掀出去 —— 他飞起来、落在三个身位外躺着（不换边、不扛不过肩）；压起身照旧。
- 搂膝拗步是接腿摔：他出腿我按拿 = 搂住腿、上步一掌推出去（打飞）。
- 采的弱点和擒拿一样：任何打击在抓到之前打断它；蹲着抓不到（要搂膝）。

## 六、连招（势）

打中了才接得上（取消照通用的规矩：`cancel`），每一下都慢（前摇 18 起），靠上一下的硬直长；一个势最多三下，打完就收。

- 掌 → 掌：高探马（高探一掌，上段、失衡）→ 掌：穿掌（直插，失衡、收势）。
- 掌 → 重：指裆捶（打倒，下砸）。掌 → 掌 → 重：白鹤亮翅（对空，打倒，像冲天炮）。
- 重 → 重：双峰贯耳（两拳贯耳，上段，打倒）。重 → 掌：顺拦肘（贴身肘）。重 → 踢：转身摆莲（转身外摆腿，打倒，最疼的腿）。
- 踢 → 踢：摆莲（外摆腿，打倒）。踢 → 掌：上步七星（落步上前一掌）。踢 → 重：弯弓射虎（落步双拳，打倒）。
- 连招里的每一下也能按住蓄（劲接着涨），打完一套发劲收尾是它的大套：掤按（蓄一段）→ 高探马 → 蓄满双峰贯耳打飞。连击衰减照旧。

## 七、跨派、三角

- `MATCHUPS['trad|taiji']`、`MATCHUPS['wc|taiji']` 两张表：系别那一套共用（掌 = 拳系、捶 = 重系），另外写的只有：擒拿克掤（蓄势里被抓就是被抓）；劲 2 以上的发劲，霸体吃不住、咏春接不住；跌岔是下段腿（站着接不住、化不了）。
- 传统格斗怎么打太极：抓（它蓄着跑不了）、下段、跳进去、退出去等它打空、卸力（卡时机）、别在它蓄势的时候出手上的招。
- 咏春怎么打太极：拉手（拉它蓄着的那只手，进搭手）、截腿 / 截脚、下段、劲还没到 2 的时候读招接；劲 2 以上的发劲只能挡、只能躲。
- 太极怎么打传统格斗：化它的拳脚、借力发劲；看见它要抓就松开；捋它的重拳、腿；采住打飞。打咏春：咏春手短、贴得近 —— 捋它的连环冲拳（第二下起拍子固定，捋得准）、靠、采；别蓄太久（它拉手快）。

## 八、动作和画面（照参考图，侧面、朝对手）

- **站姿 = 单鞭**（`tj_stance_single_whip.png`）：前手立掌在胸前、掌心朝对手偏里（看得见手指）、手指朝上；后手勾手举在身后肩高（五指捏在一起朝下、手腕弯着）；马步大开（两脚比传统格斗的站姿宽一倍上下，前 40 / 后 -45 上下，膝盖都弯着，髋低一点 hy 66 上下）；身子正、头正。只是画面，身子的判定和别人一样（两人中心距）。
- **起势 / 收势**：回合开始的那一下从起势（`tj_cloudhands_seq` 1 ～ 3：起势 → 提掌 → 抱球）走到单鞭；赢了的姿势是收势（14 ～ 16：收式合臂 → 下按 → 收势）。
- **云手**（`tj_cloudhands_seq` 4 ～ 6、`tj_defense_seq` 05）：边挡边走的动作，两只手在身前一前一后画圈，走一步换一次。
- **揽雀尾**（`tj_attack_seq` 2 ～ 6）：掤（3，小臂横在身前往前撑）→ 捋（4，两手往回往下带）→ 挤（5，后手贴着前手小臂往前挤）→ 按（6，双掌往前推出）。蓄一段就是走一格。
- **搬拦捶**（`tj_cloudhands_seq` 9 ～ 11）：搬（9，前手往外一搬）→ 拦（10，后手往前一拦）→ 捶（11，拳从腰间冲出）。
- **拗步推掌**（`tj_cloudhands_seq` 7 ～ 8）= 搂膝拗步（接住腿以后那一推）、玉女穿梭（前 + 拳）的样子。**穿掌、撩掌、肘、推掌、冲掌**（`tj_attack_seq` 7 ～ 11）：穿掌、高探马（撩）、顺拦肘、按、撇身捶的样子从这几格取。
- **掤（挡）、捋、十字手**（`tj_defense_seq`）：沉屈守中（01）= 蹲挡；提掌封门（02）/ 上架卸力（03）= 站挡的高位；外拨化劲（04）/ 抱圆接劲（08）/ 转腰牵引（09）= 捋住以后把人引过去那一下；下拦护腹（06）= 蹲挡；后撤避锋（07）= 倒卷肱的退步；双掌横封（10）/ 拨掌拒敌（11）= 挤；收势归中（12）。
