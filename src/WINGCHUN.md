## 〇、Jack 定的方向

- 2.9 的迎春拳只是换了动作的传统格斗，不要。每一派在按键上就要不一样。名字改回「咏春拳」（拳种名字没有版权；不出现叶问的名字、肖像、电影台词）。
- 动作像叶问打桩：两只手在中线上左右交错、翻（摊膀伏）、换门，带肘击。不要一上一下、手像蛇一样游。
- 玩法也和打桩有关：手搭上了就在手上做文章。
- 对面连招的时候，咏春一定有办法按某个组合键反击，但这个组合键比较复杂 —— 操作复杂、上限高。
- 五个键：拳、踢照旧攻击；拳 = 两只手轮流打；重（K）更像一记重拳，新设计；挡 = 手掌来回格挡，长按在对面连招时进一套互动；拿照样是擒拿。
- 招式自己的样子：摔不能和传统格斗一样；招名贴近咏春；掌往里翻要看得出来。

## 待定的六条（定了）

1. 寸拳（重键点按）有霸体，只吃一下拳，蓄劲的时候没有。三角照旧（重克拳）。
2. 搭手：进去以后第一下要在 16 帧里按；之后每一步按在拍子上（上一步快完的时候到完了以后 8 帧之内），慢了就脱手。
3. 咏春打咏春做手型小三角：膀克摊、摊克伏、伏克膀。
4. 顺 ≥ 3 破霸体：不做（顺只在一直打中的时候涨，他在硬直里，用不上）。
5. 蝴蝶掌留着：拉手扣住手腕以后什么都不按，最后自动两掌推出去。
6. 重 + 蹲 是沉肘（跪马沉身，肘往下压，下段）；低掌给拳 + 蹲。

## 一、底子

**每一派自己的按键语法。** 引擎在几个地方先问这一派「这一下你怎么解释」：站着按键、出招中按键（接招）、挨打的硬直里、挡住的硬直里、卸开以后、挡的时候被打到、两边的招撞上、画架势。这一派不管的才走通用的（传统格斗就是通用的那套，玩起来一点不变）。以后的拳派各写各的，不往通用代码里加某一派的特例。

**顺是咏春唯一的资源。** 一直打中、按在拍子上、搭手里翻对了手都涨顺；顺高了出手快、伤害高、他硬直长。打空、被挡、过拍、挨打、停手就清零。搭手里翻手也是在涨顺，不另设一种「势」。

## 二、五个键（站着的时候）

- **拳**：冲拳（前手日字冲拳）。接着按在拍子上就是连环冲拳（见第三节）。
  - 前 + 拳：**标指**（四指往前插，射程长、伤害低）。正好插在他出手的那只胳膊上 = 把他的手挑开，进搭手（顺 2）。
  - 蹲 + 拳：**低掌**（下段）。
- **重**：**寸拳**。沉身、后手拳贴着胸口炸出去：射程短、疼、霸体吃一下拳；打中他踉跄一下。
  - 按住 = **蓄劲**，最多 20 帧，松开那一拳越蓄越疼、打得越远；蓄满 = **寸劲破体**（霸体吃不住，打倒）。蓄的时候挨打白蓄，也没有霸体。
  - 前 + 重：**批肘**（从耳边往下斜劈，贴身，打倒）。
  - 后 + 重：**拐肘**（转马横扫，身侧、身后一点也扫得到）。
  - 蹲 + 重：**沉肘**（跪马往下压，下段，打中失衡）。
- **踢**：**正撑脚**（中段，近、快、伤害小）。蹲 + 踢 = **截脚**（下段，专截地上的腿，交手克腿；踢中他失衡）。拳打中以后接踢 = **侧撑脚**；踢接踢 = **连环撑** → **踩膝**（打倒）；转马以后按踢 = **转马撑**（打倒）。
- **拿**：**拉手**。他出拳出掌的那几帧伸手 = 拉住他的手（拉手反击，进搭手，扣着手腕，顺 2）；站着、挡着不动的人 = 扣住手腕进搭手。拉不住腿。蹲 + 拿 = **截腿**：接住地上的腿（他失衡，你先打），抓蹲着的人进搭手。
- **挡**：见第四节（拍手、黐手、耕手）。挡 + 拳 = **截打**（从手上直接截出去，出手前几帧打击无敌）。按着挡朝对手双击 = **转马**（闪身，只躲得过重拳，躲过了自动转马掌）。
- 气满 重 + 踢 = **连环寸拳**（大招）；挨打时 重 + 踢 = 爆气；冲刺叫追形；跳起来：飞身冲拳、落掌、飞撑脚、落膝。

## 三、连环冲拳和拍子

- 冲拳打出去以后，下一拳要按在拍子上：拍子是这一拳打出去（判定开始）以后的固定一段时间，顺越高拍子越快（越打越快）。
- **按在拍子上**（拍点前 3 帧到后 2 帧）：下一拳对着拍点打出去（按早一点的等到拍点，按晚一点的出手快一点补上），两只手轮流：冲拳 → 后手冲拳 → 前手立掌 → 后手冲拳 → 前手冲拳 → 后手立掌 → 前手冲拳 → 第 8 下寸拳收势（打倒）。打中了顺加一级。
- **抢拍**（按早了）：这一拳晚出 3 帧，顺不涨（他有空挡）。
- **过拍**（按晚了）：连断了、顺清零，这一拳变回起手的冲拳（慢）。
- 不看打没打中：打空、被挡也照样能按着拍子接着打（真的连环冲拳就是这样），只是顺清零。被挡的时候每一拳之间他有几帧空（推挡、卸力、跳）。
- 刚起手的空照旧：头两拳连得上，第 2 拳和第 3 拳之间有一点空，一直按着挡的人第 3 拳挡得住；连上三拳以后，按在拍子上就跑不掉。
- 连环拳里按重 = 提前收势（寸拳，打倒）；按踢 = 侧撑脚；按拿 = 拉手（进搭手）。一串最多 8 下。

## 四、挡：拍手、黐手、耕手

- **点一下挡 = 拍手**：刚按下挡的那几帧，一只掌往前一拍。正好拍在他手上的招（拳、掌、肘、肩，空中的拳脚也算）上 = 拍开，他失衡、你先打（顺 2）。腿、下段、擒拿拍不开。两次按挡隔得太近没有拍手（防乱按，和传统格斗的卸力一样）。
- **按住挡 = 黐手**：两只掌在中线上来回翻（摊 → 膀 → 伏）。正面打过来的中段、上段（拳掌肘、腿）被黏住：只吃三成，我不进挡住的硬直，直接进**搭手**（我先手）。下段、擒拿黏不住（擒拿克黐手，这是咏春的弱点）。空中的招、大招只当挡住。
  - 按住挡 + 前 = 摊手（慢慢往前压），+ 后 = 膀手（慢慢退），+ 蹲 = 耕手。黏住的那一下手型对上了（他前手的招对摊、后手的招对膀、腿和下段对耕）= 一进搭手就顺 1。
- **蹲着点挡 = 耕手**：拍开地上的腿、下段（他失衡，你先打）。**蹲着按住挡**：黏住下段、中段。

## 五、搭手（手搭上了）

**怎么进**：黐手黏住；拉手扣住站着、挡着的人；拉手反击拉住他打过来的手；标指挑开他的手；截腿抓住蹲着的人；黐手破连（第六节）。两个人贴着、手搭着，他被黏住动不了，算在硬直里。

**先手的一方（我）**：搭手开头要在 16 帧里按第一下；之后每一步按在拍子上，慢了就脱手（两边分开、谁也不亏）。

| 按 | 是什么 | |
|---|---|---|
| 前 / 后 / 蹲 | 翻手：翻成摊 / 膀 / 伏（一步一拍） | 翻对一次顺 +1，最多翻 3 次。第一下翻成克他那只手的手型（前手对摊、后手对膀、腿对伏）= 破，顺 +2。翻成现在一样的手型 = 乱了，脱手，先手给他 |
| 拳 | 从现在的手打出去：没翻 = 直冲；摊 = 摊打；膀 = 膀转摊打；伏 = 伏打 | 顺越高越疼、他硬直越长；顺够了接着按拍子打连环冲拳 |
| 重 | 批肘 | 疼、打倒，但慢，他来得及甩手 |
| 踢 | 撑脚 | 把他撑开、失衡 |
| 拿 | 拉手（扣住手腕） | 扣住以后他甩不掉、拿不了；接着：拳 = 拉打、重 = 拉手批肘（打倒）、踢 = 拉手撑脚、蹲或拿 = **拉手跪马**（摔）、不按 = 蝴蝶掌推出去 |

- **拉手跪马**（咏春的摔，代替过肩摔）：扣住他的手腕往回一拽、退半步沉身跪马，顺着把他的手往下往前带 —— 他被拽得往前扑倒，脸朝下摔在你面前（不扛、不过肩、不换边），你站在他头边上压他起身。
- 完整的一套：后（膀）→ 前（摊）→ 拳（摊打）→ 拳 → 拳 …… → 重（收势），顺一路涨满。
- 没翻手（顺 0）就直接打，伤害小、他硬直短，接不上连环冲拳 —— 想打一大套就得冒险翻手，翻的那几拍他有机会跑。

**被黏住的一方（他）**：
- 后 + 挡 = **甩手**：把手甩开、往后退半步。甩开那一下我按拳 = **甩手直冲**（必中，来留去送），所以甩手也不是白甩。
- 拿 = **反拿**（擒拿克黐手）：在我翻手的那一拍里按 = 抽手反抓（照他那一派的擒住接下去）；我在出拳、出肘的时候按，或者我扣着他手腕，抓不到，还被黏死（这一次搭手里他什么都按不了了）。
- 被扣住手腕（拉手进来的）：刚扣住那几帧按拿 = 挣脱（和擒拿一样）；拉手反击扣住的挣不脱。
- 爆气照样能用（花半格气）。
- 他也是咏春：按住挡 + 方向摆手型。我打出去的那一下，要是他的手型克我的手型（膀克摊、摊克伏、伏克膀）= 被他化开，先手换给他。没翻手的直冲化不了。

## 六、黐手破连（对面连招的时候反击）

挨打的硬直里（站着、没被抓）按住挡 + 方向，他的下一下打过来那一刻：方向对 = 黏住，直接进搭手（我先手，顺 2）；方向错 = 这一下多吃三成。方向：他下一下是前手的招按前（摊），后手的招按后（膀），腿和下段按蹲（耕）。擒拿、空中的招、大招、顺 ≥ 3 的连环冲拳黏不住。

所以打咏春要「点」不要「连」：连得越长，越可能被他读出下一下。

## 七、跨派、三角

- 系别照旧（拳 / 重 / 腿 / 拿……），三角照旧：拳克腿、腿克重、重克拳；打击克擒拿、擒拿克格挡、格挡克打击。咏春的格挡就是黐手，所以擒拿克黐手。
- 跨派交手规则：两派的招按同一套系别比；另外截脚克地上的腿；标指撞上他手上的招 = 挑开进搭手。
- 传统格斗怎么打咏春：擒拿（黐手黏不住）、下段（站着的黐手黏不住）、点到为止（连招越长越容易被黐手破连）、在搭手里甩手或者看准他翻手的那一拍反拿。

## 八、动作和画面

- 架势：问手 + 护手，两只掌竖着，**掌心朝里（朝中线）**：大拇指画在靠身子那一侧，一眼看得出是往里翻的（以前画在前面，看着是往外翻）。立掌、护手、黐手里的摊膀伏都按手掌朝哪画。
- 连环冲拳：两手在一条线上左右交错，收回来的拳从打出去那条胳膊的肘底下抽回。
- 黐手：两只掌错开半拍翻（前手摊的时候后手伏）。
- 搭手：两人贴着、手搭着；翻手一步一个定格；翻对了手边上写一个摊 / 膀 / 伏；先手那一方手边一圈墨线，转完就该按了。
- 拉手跪马：被拽倒的人往前扑、脸朝下趴在地上，起身从趴着撑起来。
- 肘：批肘从耳边劈到腰，拐肘转马横扫，沉肘跪马往下压。

## 九、电脑

- 咏春的电脑：在拍子上连（难度决定按得准不准）、黐手、拍手、黐手破连（难度决定方向对不对）、搭手里翻手接一套（难度决定翻几下、按错多少）、甩手直冲。
- 传统格斗的电脑打咏春：看见他黐手就抓、打下段，少连多点，被黏住了甩手或者看他翻手的时候反拿。
- 平衡照旧：同一档电脑对电脑两派各打一遍，打掉的血一半上下；木头玩家打咏春的电脑五档和传统格斗差不多难。

## 十三、2.10.0 打完以后 Jack 的反馈（2.10.1 改了；做出来的数见 `NOTES.md`「2.10：咏春拳」的 2.10.1 那条）

### Jack 说的（定了）

1. **拳还是只有一只手。** 说好的两只手轮流出拳和掌。现在只有按着拍子连的时候才换手，连断了、踢完接拳、重新起手全是前手 —— 所以「拳 踢 拳 踢」这么打每一拳都是前手。要改成每按一下拳就换一只手。
2. **太超标了。** 咏春是有操作难度的英雄，可现在拳和踢来回按，对面根本没有还手的机会。量过：拳接踢不看拍子，踢完接拳又算一次全新的起手、硬直是满的，「头两下有空」这条被整个绕过去；一串八下五十血上下、中间没有空，对面按着挡也是整串按在挡里只能吃削血。
3. **咏春的特点是手腿都短。** 收益主要靠两处：对面进攻的时候反打，收益巨高；贴脸放很复杂的连招（搭手）。它自己主动进攻的收益要稍微降一降。
4. **格挡动作太奇怪。**
5. **参考图 `ref/wc_dummy_rolling.jpg`（Jack 给的，打桩的盘手，十二格）：一定要看到左右手左右交叉的感觉，不是上下交叉。** 现在游戏里只能看出上下交叉，而且关节的弯曲很反人类。

### 参考图里要照着做的

- 两只手一直在胸口到肩这一段高度，在同一个高度带里，不是一只抬高一只压低。
- 两条小臂往前斜伸，肘尖一直朝下、收在身前；不抬过肩、不往外翻、不反折。
- 换手是**左右换位**：里面那只手从外面绕出去，外面那只收进来；换的那一下两条小臂在身前交叉成一个 X（从侧面看是一前一后两条小臂叠在一起、手差不多一样高）。
- 手腕顺着小臂，掌竖着或者微微朝里，不反折。
- 脚不动，腰跟着微微拧，身子不晃。
- 连环冲拳也照这个：两拳走同一个高度的中线，收回来的拳从打出去那条胳膊的肘底下抽回，换手那一下两条小臂擦着交错。

现在的问题：黐手是摊 → 膀 → 伏一圈圈转，膀手把肘抬到肩上面、小臂斜着往下，看着就是一只手抬高、一只手压低；肘的弯向也跟着反了。

### 改法（Jack 2026-10-28 下午定的：换手照传统格斗的普通攻击那样；左右用一点点阴影分；收益先照下面做、他到时候再看）

**拳和拍子**

1. 换手照传统格斗的普通攻击那样（短拳 → 后手直拳 → 摆拳）：**连下去就两只手轮流**，不管中间夹没夹踢 —— 拳、踢、拳、踢也是一串，踢完接的拳换另一只手；一串断了（过拍、收完招站着）重新起手还是前手。立掌照旧每三拳的第三下。
2. 一串里所有的招都按拍子，不只是拳：拳接踢、踢接拳、踢接踢一样。按在拍子上才是连招；按早了是抢拍（踢晚出、顺不涨、中间有空）；按晚了是过拍（连断了，那一脚就是一记慢的正撑脚）。拳踢乱按全是洞，按准了才打得满 —— 操作难度在这里。
3. 「头两下有空」对所有连招成立：不管第二下是拳还是踢，一直按着挡的人第三下挡得住。连上三下、顺到两级以后才跑不掉，而且得一直按在拍子上。
4. 被挡的时候一串里每一下之间都留两帧的空，踢也一样；传统格斗的推挡、卸力在空里做得出来。八下封顶照旧。

**收益：反打和贴脸最高，主动进攻降一降**（现在量到的：中立起手的连环冲拳八下 43，反打以后 46，搭手里破了再打 47 —— 三个差不多，不对）

5. 中立起手（没反打、没搭手）打出去的连环拳每一下打八折：一串八下 35 上下。射程本来就短（冲拳 84 ～ 86、正撑脚 100；传统格斗短拳 92、腿踢 126），不再动。
6. 反打进来的（拍开、耕开、拉住、标指挑开、黐手破连、卸开）顺 3 起（现在 2），一串 50 上下。
7. 搭手里翻手翻满再打最高，55 ～ 60；拉手跪马以后压起身照旧。
8. 主动的踢（正撑脚、截脚）、寸拳照旧。

**格挡的样子**

## 十四、动作的样子（Jack 2026-10-28 下午定的；参考图都在 `ref/`，侧面、朝左）

### 日字冲拳 `ref/wc_chung_side.jpg`

Jack：它的普攻就是照打桩那段视频来的，和普通直拳不一样 ——

- 大臂是往下的：肘尖朝下、贴着肋骨那一侧，不往外抬、不往上甩。
- 小臂是平的、直的：从胸口中线水平往前送，和地面平行。
- 拳头竖着，往上翘一点：拇指在上，手腕往上翘，拳面微微朝上，侧面看拳头在小臂末端翘起来。
- 打到最远胳膊也不是一条直线：肘在拳头后面偏下，大臂小臂之间还有角度；力是肘往前顶的，不是肩甩的。
- 高度是胸口到心窝，比肩低；伸出去比直拳短 —— 手短就是这么来的。
- 收回来的那只拳抽回胸口，在打出去那条小臂底下、离它的肘不远；新的一拳从它上面出去，两只拳一直在同一条中线上滚着换。

参考图里看得清的：身子正着不前倾，前臂水平，肘在小臂线下面一拳多，后面那只拳收在胸口、正好在前臂肘弯底下。

### 冲拳打出去的整个过程 `ref/wc_chung_seq.jpg`（六格，从左到右；单张 `wc_chung_seq_1.jpg` ～ `_6.jpg`）

Jack：这就是一拳打出去的全部顺序。**记住手臂和手腕的角度关系：胳膊不是完全伸直的，手腕往上弯一点点。** 不是单手攻击，两只手轮流这么做。

1. 前手的拳在胸前半伸着，小臂水平、肘弯着朝下；后手的拳收在前手小臂后面、贴着胸口。
2. 前手往前送：小臂还是水平的，肘还弯着；拳竖着、手腕上翘。后手的拳在胸口、前手肘弯底下。
3. 前手再往前，快到头了，小臂略微往上扬；肘还有一点弯。
4. 前手到头：肘还是没伸直，手腕上翘。这时候后手张开成竖掌，贴到前手的肘弯 / 小臂内侧上（要从这条胳膊上面出去）。
5. 换手的那一下：两只拳都在身前差不多一样远、一样高，后手的拳从前手小臂上面滚出去，两条小臂一上一下擦着交错。
6. 后手到头，样子和第 4 格一样；前手收回胸口、在后手肘弯底下。接着从第 1 格再来，两只手换过来。

打出去那条胳膊从头到尾：大臂垂着、肘朝下，小臂水平略扬，拳竖着、腕上翘，到头也留一点弯。

### 站姿的手（问手 + 护手）`ref/wc_stance_side.jpg`

- 前手（问手）：从胸口往前伸，小臂差不多水平、略微往上扬，肘沉在肋骨旁边、不伸直；掌张开，手指朝前略朝上，掌心朝里偏下，手腕微微往上翘。
- 后手（护手）：竖掌，掌心朝里（朝中线），手指朝上偏前，收在前手小臂后面、靠近前手的肘弯，胸口高度。
- 两只手一前一后都在中线上，两个肘都朝下；身子正着，不前倾。
- 从侧面看：前手伸出去的长度和冲拳差不多（也是肘不伸直），后手的掌正好叠在前手小臂的后半段上。

### 出拳的时候身子（Jack 2026-10-28 晚上定的）

Jack：照项目书的图先把 J 的出拳和站姿改掉；虽然只有六张图，要连贯起来做。**人物出拳的时候身子不用往前伸很多，一点点就够了 —— 就像在那打桩一样，躯干是稳住的。**

- 一串连环冲拳里身子一动不动：不前倾、不往前冲、不一冲一弹，头一直在一个地方；只有两只手轮流打，肩膀跟着左右换一点（送肩）。

- 整个人往前挪的那一点是招式本来的前冲（追着打，射程、前冲这些玩法的数不动）。
