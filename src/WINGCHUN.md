# 咏春拳 · 设计稿（2.10 要做的；2.9 的「迎春拳」重做）

Jack 2.9 以后定的方向（2026-10-28）：2.9 的迎春拳只是换了动作的传统格斗，不要。以后要做很多拳派，每一派在按键上就要不一样。咏春拳（2.9 叫「迎春拳」，就是叶问那种咏春；拳种名字没有版权，改回「咏春拳」，只要不出现叶问的名字、肖像、电影台词）要做到：

- 动作像叶问打桩：两只手在中线上左右交错、翻（摊膀伏）、换门，带肘击；不要 2.9 那种一上一下、手像蛇一样游的动作。
- 玩法也和打桩有关：手搭上了在手上做文章。
- 对面连招的时候，咏春一定有办法按某个组合键反击出去，但这个组合键比较复杂 —— 操作复杂、上限高的角色。
- 五个键：拳、踢照旧是攻击；**拳 = 两只手轮流打**（打桩那样）；**重（K）更像重拳**，要新设计；**挡 = 手掌来回格挡**，动作和拳很像，长按在对面连招时进入一套互动（叶问那种）；**拿照样是擒拿**。重、挡、拿三个键动作主体差不多（都是手上的功夫），分工不同。

下面是设计。标「待定」的要 Jack 拍板。没标的照做。

## 一、底子：三个新东西

**1. 每一派自己的按键语法。** 现在 `pickVariant` 是「一键一招 + 打中接下一键」，这是传统格斗的语法。改成每一派提供一个输入解释器 `interpret(按键, 方向, 按住的键, 当前状态)` → 这一派决定这一下是什么（出招、换手型、进状态、什么都不是）。战斗、动画、联机不用动，只是多一层。以后的拳派各写各的解释器。

**2. 搭手（黐手）状态。** 咏春的核心。两人手搭上了（我的手黏住他的手上的招，或者我拉手拉住他），进入搭手：时间短（搭手窗 `TOUCH_WIN`，约 18 帧），两边都能按，按的东西是「手上的功夫」而不是普通出招。窗一过、或者谁的手脱开了，回到普通状态。

**3. 节拍。** 咏春的连环拳不看「打中了接」，看按在不在拍子上。每一拳的「拍点」是上一拳判定开始后第 `BEAT` 帧左右（前后各 `BEAT_TOL` 帧）：按在拍子上，下一拳正常出且顺加一级；按早了（抢拍）下一拳晚出几帧；按晚了（过拍）连断、顺清零。这就是「操作复杂」的第一层：不是乱按就连得上。

## 二、五个键

### 拳（F）：日字冲拳

- 单按：前手冲拳。连按（在拍子上）：后手、前手、后手……两只手轮流，收回来的拳从打出去那条胳膊的肘底下抽回（2.9.1 已经摆好的那一套动作）。
- 第 3 下起有顺：出手快一点、疼一点、他硬直长一点；最多 8 级。打空、被挡、过拍、挨打就断。
- 拳 + 前：标指（手指往前插，射程长一截，伤害低，打中他的手上的招 = 把他的手挑开，进搭手）。
- 拳 + 蹲：低掌（下段）。
- 连环拳打到第 8 下自动收势寸劲（现在的寸拳）。
- 刚起手的空照旧留着：头两下之间他一直按着挡挡得住；连上 3 下顺了就没空。

### 踢（H）：撑脚

- 腿永远短、快、伤害小，而且要「手脚齐到」：单按踢是正撑脚（中段，射程 100）；拳打中以后接踢 = 侧撑；踢接踢 = 连环撑 → 踩膝；转马以后按踢 = 转马撑（打倒）。蹲 + 踢 = 截膝（下段，截地上的腿）。
- 腿在三角里照旧克重、怕拳。

### 重（K）：寸劲系（新设计）

2.9 的重键是拍手 / 摊打那一串，手一上一下游，不要了。重键改成咏春「发劲」那一类，看着就是一记重拳：

- 单按：**寸劲拳**。沉身、后手拳贴着胸口、一寸一寸炸出去。前摇比传统重拳短（基准 8）、射程短（80）、伤害大（14）、有霸体（重系，克拳）、打中轻微失衡。这就是它的重拳。
- 按住：蓄劲。按住越久（最多 20 帧）松开那一拳越疼、击退越远，蓄满 = 寸劲破体（霸体吃不住，打倒）。蓄的时候挨打白蓄。
- 重 + 前：**批肘**（从上往下斜劈的肘，贴身，射程 60，打倒）。
- 重 + 后：**拐肘**（横着扫的肘，转马带出来，打背后 / 身侧的人也打得到）。
- 重 + 蹲：**沉肘 / 低掌**（往下压，打下段，蹲着挡也挡不住的中段肘另算，待定）。
- 搭手里按重：**肘**（贴着他的手直接拐肘进去，搭手里最疼的一下，见第三节）。
- 连环拳里按重：寸劲收势（提前收）。

待定：寸劲要不要霸体。有霸体 = 它就是传统意义的重拳，三角不变；没霸体 = 咏春没有「硬吃」这一说，靠搭手克拳。我倾向有霸体但只吃一下、而且蓄劲时没有。

### 挡（R）：黐手

动作和拳很像，但是两只掌在中线上来回翻（摊 → 膀 → 伏 → 摊……），这是叶问打桩那个「手来回弄」。

- 点一下：**拍手**（一只掌往前一拍）。拍开正面打来的手上的招，他失衡（和 2.9 一样）。
- 按住：**黐手**。两只掌一直滚着，打过来的中段、上段的手上的招和腿被黏住（吃三成，像挡住，但我不进挡住的硬直）—— 黏住的那一下就进**搭手**。按着方向慢慢往前压。下段、擒拿黏不住（擒拿克黐手，这是咏春的弱点，留着）。
- 按住 + 方向 = 换手型（也是搭手里的输入，见第三节）：前 = 摊手，后 = 膀手，蹲 = 耕手 / 伏手。
- 按住挡 + 朝对手双击：转马（闪身，和现在一样只躲得过重系）。

挡的时候两只手一直在动，这就是他要的「格挡的动作和拳很像」。

### 拿（T）：拉手 / 擒拿

- 单按：拉手。他出拳出掌的那几帧伸手 = 拉住他的手（进搭手，而且是我占主动的搭手）；站着不动的人 = 擒住（后续：拳 = 拉打、踢 = 扫踢摔、重 = 肘、后 + 拿 = 转马摔）。拉不住腿。
- 蹲 + 拿：截腿（接地上的腿、抓蹲着的）。
- 搭手里按拿：**拉手**，把他拽进来接肘或者摔（见第三节）。

## 三、搭手：咏春的「对面连招我也能反击」

### 怎么进搭手

1. 我按住挡（黐手），他的手上的招 / 腿打到我的手上 → 黏住 → 搭手（我占先，他的那一招被黏住）。
2. 我拉手拉住他出拳的手 → 搭手（我占先更多）。
3. 我标指挑开他的手 → 搭手。
4. 他在连招里打我（我在挨打的硬直里）：这是关键 —— **挨打的硬直里按住挡 + 对的方向 = 黐手破连**。他下一下还没打到，我的手先搭上去。方向要对：他下一下是前手的招按前（摊），后手的招按后（膀），腿按蹲（耕），擒拿按不了（擒拿克黐手）。按错了方向 = 这一下吃全额再加三成；按对了 = 黏住、进搭手。这就是「对面连招时一定有办法反击，但组合键复杂」：要看清他连招的下一下是哪只手，在硬直里按出对的方向。

### 搭手里能按什么

搭手窗 `TOUCH_WIN` 帧（约 18 帧，待定）内，两边都能按。搭手里的输入不是普通出招，是手上的功夫；按一串、按对了就是一套反打，按错或者过了窗就脱手。

我方（占先的一方）：

| 按法 | 是什么 | 收益 |
|---|---|---|
| 拳 | 搭手直冲：手贴着他的手直接打进去 | 小，但最快，稳 |
| 前 → 拳 | 摊打：摊手一托、拳从旁边打进去 | 中，打中接连环拳（顺从 2 级起） |
| 后 → 拳 | 膀手转摊打：膀手一滚、转马、拳进去 | 中大，专破重系（他寸劲、重拳被膀开） |
| 蹲 → 拳 | 伏打：伏手压住、拳打 | 中，专破腿 |
| 拿 → 重 | 拉手批肘：拽进来、肘劈下去 | 大，打倒 |
| 拿 → 踢 | 拉手撑脚：拽进来、膝 / 脚撑他的腿 | 中，失衡 |
| 后 → 前 → 拳 → 拳 → 重 | 膀 → 摊 → 连环 → 肘：完整的一套 | 最大，打倒 + 顺满 |
| 重 | 直接肘 | 大但慢，他来得及脱手 |

每一步都有自己的时限（`TOUCH_STEP` 约 6 帧内按下一步），按错一步 = 脱手，还把先手让给他。整套按完要在搭手窗里按五个键三个方向，这是上限。

对方（被搭住的一方）：

- 不按：吃我方按出来的那一套。
- 拿：擒拿克黐手 —— 搭手里按拿 = 把手抽出来反抓（我方正在按序列的话被抓住）。但拉手拉住的搭手抽不出来（拉手是我拽着他）。
- 后 + 挡：甩手，脱开搭手，各退半步。甩手那一刻我方有一个「甩手直冲」的窗：甩开的瞬间按拳必中（来留去送）。所以甩手也不是白甩的。
- 对面也是咏春：他也能按同样的序列，谁的手型克谁的（摊克拍、膀克摊、伏克膀 —— 一个小三角，待定），搭手变成两个人互相翻手，谁先错谁挨打。这是咏春内战的样子。

### 传统格斗怎么对付搭手

- 擒拿：黐手黏不住，搭手里按拿反抓。
- 下段：下盘拳、扫堂腿黐手黏不住。
- 不连：打一下就停，不给他黐手破连的机会 —— 打咏春要「点」不要「连」。
- 重拳霸体：黐手破连按错方向的那一下，霸体照样走。

## 四、三角、顺、资源

- 系别照旧（拳 / 重 / 腿 / 拿），三角照旧：拳克腿、腿克重、重克拳。咏春的差别在「怎么做到」：它克重主要靠膀手转摊打（搭手），不靠腿；它的重拳射程短，要贴上去。
- 顺：只有拳系的招、搭手里打出去的招涨。断了清零。顺 ≥ 3 的拳霸体吃不住（待定，这是咏春对霸体的另一个答案）。
- 气：和传统一样。大招（气满重 + 踢）照旧连环寸拳。
- 搭手没有资源，靠时限和按错就脱手来限制。

## 五、动作

- 架势：問手 + 護手，两只掌，侧身（2.9 的）。
- 连环拳：2.9.1 的左右交错（两手一条线、换手时小臂交错、收回的拳在肘底下）。立掌也在这条线上。
- 黐手：摊 → 膀 → 伏循环。摊：掌心朝上、肘沉、小臂往前托；膀：肘抬到肩高、小臂斜着横在身前、掌心朝下；伏：掌心朝下压、手腕弯。两只手错开半拍滚，前手摊的时候后手伏。
- 搭手里每一步一个定格姿势 + 短的过渡，手不离中线、不上下游。
- 肘：批肘从耳边劈到腰，拐肘转马横扫，沉肘从胸口压下去。
- 2.9 的那几招去留：摊打 / 拍打 → 只在搭手里；蝴蝶掌 → 删（或者改成蓄满寸劲的样子，待定）；拍手、耕手 → 挡键点按 / 蹲按；盘手 → 黐手；拉手、截腿、撑脚一家、寸拳、空中四招、转马、追形照旧。

## 六、电脑

- 咏春的电脑：会在拍子上连、会黐手破连（难度决定方向按对的概率 —— 入门几乎不会，终极几乎全对）、搭手里会按序列（难度决定按几步、按错多少）、贴身先黐手、黏住就反打。
- 传统格斗的电脑打咏春：少连多点、擒拿多、下段多、看见黐手就抓。
- 平衡量法照旧：电脑对电脑同一档两派各打一遍，打掉的血占比要在一半上下；木头玩家打咏春电脑五档和传统差不多。
